# 💫 About Me:
Final-year B.E. Computer Science student at Sri Ramakrishna Institute of Technology, Coimbatore, passionate about building full-stack web applications with the MERN stack and Python. I've interned in backend and full-stack development, where I improved API response times by 35% with FastAPI and built real-time features using Socket.io. My projects include SnapLink, a URL shortener with analytics, QR export and JWT auth, and an Exam Seating Arrangement Generator with a department-aware seating algorithm and PDF export. I was also part of the team behind UrbanTrail, a real-time bus tracking app that won Top Software Team at the Smart India Hackathon (internal round). I'm currently looking for opportunities to build scalable, reliable software and keep learning.
